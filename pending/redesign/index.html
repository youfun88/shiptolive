5 個首頁版型，請挑一個

五個版型都賣同樣三件事：科技行銷、軟體開發、AI 導入。內容和規則一樣（真實客戶、標明來源的數據、沒有保證、沒有新價格），差別在版面、互動和第一印象。每個都有中文版和英文版，手機和電腦都能看。點截圖或「開啟」就能看完整頁面。

這些頁面都是手工寫的靜態 HTML，沒有用 base44：base44 需要你的帳號，而且網站會放在它的平台上（不在 GitHub Pages，對 SEO 不利）。後台畫面是真實的 admin 介面跑在示範模式，數字是示範資料。

我的推薦：版型 4（互動診斷）。它用客戶自己的話問「你現在最卡的是？」，把三種服務分流，再帶著答案進聯絡表單，最可能變成預約；扮演「懷疑的台灣中小企業老闆」的審稿也把它排第一。想要更穩重的感覺，就選 2 或 3；4 的問答卡也可以搬到 2 或 3 的首屏上。

版型 1Bento

深色・Apple / Linear 風格

深色背景、細邊框的方格版面。首屏一句話，下面三個服務各一個會動的方格：後台畫面在筆電框裡、軟體估算器、週報計時器 2:00:00 → 0:10:00。每個服務再展開成自己的方格區塊。

優點

  • 最有「產品公司」的高級感
  • 三個服務 5 秒內看懂
  • 動畫多但克制，減少動態設定時會關掉

取捨

  • 和現在的淺色網站差最多
  • 手機版約 18,000px，偏長
  • 深色在戶外陽光下較難讀

版型 2捲動故事

Scroll story・石灰紙色＋深藍綠

邊捲邊講故事。電腦版：科技行銷的後台會隨著五個章節一步步組起來（健檢 → 缺口 → 每週修正 → AI 開始引用 → 手機核准）；軟體開發是模組一塊塊拼上；AI 導入是週報流程逐步播放。手機版改成每章圖文直排，不會卡住。

優點

  • 最會「講流程」，老闆看得懂我們每個月在做什麼
  • WU LAW 成果在第 1.5 個畫面就出現
  • 三個服務深度一致

取捨

  • 電腦版的捲動特效要實際滑才看得出來
  • 後台示意圖在手機上偏小（可點開放大）
  • 英文版較長

版型 3雜誌

Editorial・淺色・襯線大字

像一本安靜的商業雜誌：大字標題、章節編號 01 / 02 / 03、引言、後台截圖當成「圖 1、圖 2」。每個數字旁邊都有註腳，頁尾有完整的資料來源清單。手機底部有固定的「預約 20 分鐘」按鈕。

優點

  • 最有信任感、最像 B2B 顧問
  • 每個數字都標了來源，可查證
  • 手機讀起來像一篇好文章

取捨

  • 最長（手機約 21,000px），需要讀者有耐心
  • 動畫最少，「哇」的感覺較弱
  • 中文標題用 Google Fonts 襯線字（多一點載入）

版型 4互動診斷推薦

Interactive diagnostic・像一個 App

首屏直接問：「你現在最卡的是？」客戶找不到你 / 流程太手動 / 需要一套系統。點一個，再回答兩題，就得到一張「診斷結果」：可能的問題、我們會先做什麼、相關的真實成果，按鈕會把答案自動帶進聯絡表單。下面仍完整介紹三個服務。

優點

  • 訪客自己分流，聯絡表單帶著情境進來（最容易轉成預約）
  • 結果可以用連結分享
  • 感覺像產品，不像傳單；手機版首屏就有成果數字和預約按鈕

取捨

  • 想直接瀏覽的人要先捲過問答卡
  • 診斷結果的文字在 JS 裡（同樣的事實下方都有寫，SEO 不受影響）
  • 手機約 18,000px

版型 5學院＋工作室

Academy + studio・暖色・AI 導入優先

以 AI 導入為主角：「把 AI 從工具，變成團隊的同事」。首屏是一條學習路徑（免費資源 → 個人工作坊 → 企業內訓 → 代建自動化 → 持續支援），接著是週報 / 客服 / 報價的前後對照動畫、課程大綱、適合誰 / 不適合誰。後半段「工作室」介紹科技行銷和軟體開發。

優點

  • 最適合往「AI 導入」轉型的方向
  • 像課程頁但沒有倒數計時、假人數
  • 「適合 / 不適合」區塊很誠實

取捨

  • 科技行銷（現在主要收入）排第二
  • 課程時數、價格都還沒定（目前寫洽詢）
  • 免費資源（YouTube、LINE 社群）還不存在，寫「陸續推出」
