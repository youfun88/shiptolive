隱私權政策

這份政策說明夏裕科技股份有限公司（統一編號 90173045，以下稱「我們」）在 shiptolive.com 和客戶後台 admin.shiptolive.com 收集哪些資料、怎麼使用，以及您可以怎麼要求查詢或刪除。

我們收集的資料

  • 瀏覽網站：我們使用 Google Analytics 統計網站的使用情形（例如造訪頁面、裝置類型、大約地區），會使用 cookie。這些統計不用來辨識個人。
  • 聯絡與預約：您填寫聯絡表單或透過 Calendly 預約時，我們會收到您提供的姓名、Email、公司名稱和留言內容。
  • 客戶後台登入：客戶用 Google 帳號登入 admin.shiptolive.com 時，我們只取得您的姓名和 Email，用來確認您可以看哪一個網站的報告。我們不會讀取您的 Gmail、雲端硬碟或其他 Google 帳戶資料。
  • 客戶授權的網站資料：客戶授權後，我們讀取該網站的 Google Search Console 等成效資料，用來製作報告和改善網站。
  • 簽約資料：線上簽約時，我們保存公司資料、方案內容、簽名與印章圖檔，以及簽署時間，用來成立和保存合約。

資料的用途

只用於提供和改善我們的服務：回覆您的詢問、安排會議、提供客戶報告、簽署與保存合約、開立發票和帳務往來。我們不出售您的資料，也不把資料用於廣告投放。

我們使用的服務

為了提供服務，資料會存放或經過以下服務商：Google（Analytics、登入、Search Console）、Calendly（預約）、Vercel 與 GitHub Pages（網站主機）、Supabase（資料庫）、Brevo（寄送 Email）。這些服務商只依我們的指示處理資料。

Google 使用者資料

我們透過 Google 登入取得的資料（姓名、Email），只用於登入和權限確認，使用方式遵守 Google API Services User Data Policy，包含 Limited Use 規定；不會轉給第三方，也不會用於廣告。

保存與您的權利

合約與帳務資料依法律規定的期間保存；其他資料在不再需要時刪除。依個人資料保護法，您可以要求查詢、更正、停止使用或刪除您的個人資料，請來信 yufan@shiptolive.com，我們會在合理期間內回覆。

政策更新

政策內容如有更新，會公布在這個頁面並更新上方日期。
