Why we picked Payload CMS

We compared WordPress, Strapi and Sanity. Payload won for practical reasons.

  • Open source, no license fee

    MIT licensed, no per-seat monthly fee. You pay for the build and support, not software rent.

  • Same code as the website

    Admin and site both run on Next.js, so the site stays fast and there is no separate admin server.

  • Easy for non-technical staff

    Updating content feels like filling in a form. Uploaded images are compressed and resized for phones automatically.

  • Drafts, preview, version history

    Save half-finished work as a draft. Roll back a mistake to an earlier version.

  • Built-in API

    Connects to LINE, CRMs, ERPs and the AI Visibility Engine. Approved articles can publish automatically.

  • Your data, your database

    Content lives in your own database. If you ever switch vendors, it all comes with you.

Is Payload secure?

Security comes from checks at every layer. Here is what Payload has built in, plus what we set up for you.

  • Open code

    Payload is open source on GitHub. Developers worldwide can read it and report problems.

  • No plain-text passwords

    Passwords are salted and hashed with PBKDF2 before they are stored. Even we cannot see them.

  • Stops password guessing

    Five wrong passwords in a row lock the account for 10 minutes.

  • Permissions down to each field

    Every content type, and every field, can have its own rules for who can read and who can edit.

  • Fewer plugins, fewer holes

    Most WordPress security problems come from plugins. Payload builds features into the system, so far fewer third-party add-ons are needed.

  • Encrypted connections and updates

    Admin, site and database talk over encrypted connections. We apply updates and security patches regularly and set up backups.

To be honest, no system is 100% secure. Account hygiene matters too: one account per person, switch it off when someone leaves, never share passwords. We set this up with you.
